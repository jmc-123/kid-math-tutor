├── data/                 ← 知识图谱数据
│   ├── 7-up/            ← 七年级上册

│   ├── 8-down/          ← 八年级下册

### 核心数据文件

每个年级目录下有 5 个 JSON 文件：

| 文件 | 作用 |
|------|------|
| `topics.json` | 知识点节点（含 id、name、type、domain、evidence、assessmentPrompt） |
| `dependencies.json` | 前置依赖边（构建 DAG） |
| `clusters.json` | 领域聚类摘要（面向家长/学生） |
| `curriculum-standards.json` | 对齐 2022 版课标 |
| `manifest.json` | 统计元数据 |

### 年级标识

grade 取值：`7-up` `7-down` `8-up` `8-down` `9-up` `9-down`

用户未指定年级时，读取所有 6 个年级的 topics.json（用于跨年级知识点匹配）。

### 关键路径

- 知识点数据：`data/{grade}/topics.json`
- 依赖关系：`data/{grade}/dependencies.json`
- 聚类摘要：`data/{grade}/clusters.json`
- 字段定义：`schema/*.schema.json`
- 模式详细步骤：`references/{mode}.md`

> 💡 **可移植性**：整个 `math-tutor/` 文件夹可独立复制到其他工作区使用，无需依赖外部仓库结构。

## 🧠 核心思维框架

本系统融合四大权威数学思维训练方法，Agent 在辅导时应根据学生需求选择合适框架。

### 1. Polya 四阶段问题解决循环

**何时使用**：默认的解题流程，适合所有问题

| 阶段 | 核心问题 | 失败信号 |
|------|----------|----------|
| **理解问题** | 未知是什么？已知什么？条件是什么？ | 学生无法重述问题 |
| **制定计划** | 以前见过类似的吗？能用定理吗？ | 直接跳到计算 |
| **执行计划** | 每步是否合理？ | 步骤跳跃无验证 |
| **回顾反思** | 答案对吗？有更简洁的方法吗？ | 只求结果不验证 |

**失败模式**：先计算后理解 → 返回阶段 1。

### 2. Friedman 八步解题训练法

**何时使用**：系统化训练解题能力，分析学生作业

1. **分析问题** — 分解题目条件和要求
2. **做表征或图表** — 画图、列表、建立模型
3. **找解法** — 识别问题类型，选择策略
4. **执行解法** — 按步骤求解
5. **检查解法** — 验证答案正确性
6. **讨论问题** — 分析存在性、解的数量、条件依赖
7. **清晰陈述答案** — 用数学语言规范表述
8. **分析完成的解法** — 寻找更好的方法、推广和迁移

### 3. 孙维刚结构化学习

**何时使用**：建立知识体系，培养解题思维

- **一题多解**：从不同角度理解问题结构
- **多题归一**：发现不同问题的共同本质
- **结构连接**：将新知识与已有知识网络连接
- **超前思维**：鼓励学生预测、推导、质疑

### 4. 王屏山傅学顺数学思维模型

**何时使用**：针对性培养特定数学思维能力

六大可训练能力：

| 能力 | 训练方法 |
|------|----------|
| **分析能力** | 分解复杂问题为简单要素，条件-需求分解 |
| **设想能力** | 假设结论成立，推导必要条件，包括"设想问题已解" |
| **归纳能力** | 从特例发现一般规律，穷举归纳、枚举归纳、数学归纳 |
| **模仿能力** | 映射关系而非表面词汇，转移已解决问题的操作序列 |
| **类比模拟能力** | 在不同领域间迁移方法，包括类比、模拟、等价变换 |
| **逻辑推理能力** | 严格证明和反例构造，包括定义、命题、推论、反例 |

## 📚 四大辅导模式

### diagnose — 错题诊断

**目标**：定位错题根因，输出薄弱链报告

**核心流程**：
1. 语义匹配错题到对应知识点（`topics.json`）
2. 沿 `dependencies.json` DAG 向前追溯，找到最底层未掌握点
3. 输出薄弱链 + 建议补强顺序

**输出示例**：

```
🔴 根因：有理数的概念（mt_ch1_003，七上）
  ↓
🟡 无理数与实数的概念（mt_ch8_003，七下）← 直接出错点
建议：先回看有理数定义，再理解无理数引入过程
```

### generate — 自适应出题

**目标**：根据诊断结果或指定知识点生成练习

**题型对照**：

| 知识点类型 | 出题类型 |
|-----------|----------|
| CONCEPTUAL | 判断题、概念辨析、举例题 |
| PROCEDURAL | 计算步骤题、纠错题、填空 |
| REPRESENTATIONAL | 画图题、数形结合题 |

**四档难度**：夯基（前置）→ 目标（本点）→ 综合（跨点）→ 挑战（下游）

### learn — 自学引导

**目标**：生成拓扑排序的学习路径

**五种内容形式**：
- **思维导图**（Mermaid 格式：前置/核心/后续/易错点）
- **视频脚本**（3-5 分钟，含生活引入 + 例题演示 + 口诀总结）
- **故事化讲解**（将抽象概念包装进情境，适合低年级或数学焦虑学生）
- **费曼笔记**（不用术语的一句话定义 + 生活类比 + 类比边界）
- **刷题清单**（答对升级、答错回退的自适应练习序列）

### build — 图谱扩展

**目标**：从教材 PDF 目录生成新的知识图谱数据

**输出**：符合 `schema/` 定义的 JSON 文件，可直接使用

## 🎯 四种思维训练模式

### polya — Polya 问题解决

**应用场景**：学生需要系统性解题指导时

**输出模板**：

```
🧠 Polya解题分析

━━ 第一步：理解问题 ━━
• 未知：[需要求解的内容]
• 数据：[已知条件]
• 条件：[约束条件]
• 可行性：[是否有解的判断]

━━ 第二步：制定计划 ━━
• 相关问题：[类似问题或定理]
• 解题策略：[选择的解题方法]
• 辅助元素：[可能需要的辅助线、辅助变量等]

━━ 第三步：执行计划 ━━
• 步骤1：[具体计算或推理过程]
• 步骤2：[继续执行过程]
• 每步验证：[每一步的合理性检查]

━━ 第四步：回顾反思 ━━
• 答案验证：[结果是否正确]
• 解法优化：[是否有更简洁的方法]
• 方法推广：[此方法可用于哪些其他问题]
```

### friedman — Friedman 八步训练

**应用场景**：需要系统化训练学生解题能力时

**核心流程**：问题分析 → 表征构建 → 方法寻找 → 执行解法 → 结果检查 → 深度讨论 → 清晰表达 → 方法提炼

### structural — 结构化学习

**应用场景**：学生需要建立知识体系和解题思维时

**核心原则**：一题多解、多题归一、结构连接、超前思维

### thinking — 数学思维训练

**应用场景**：需要针对性培养特定数学思维能力时

**能力分类**：分析能力、设想能力、归纳能力、类比能力、变换能力、逻辑推理

## 🔄 跨模式状态传递

在同一次对话中，各模式共享以下状态：

| 状态变量 | 含义 | 写入模式 |
|----------|------|----------|
| `diagnosed_weak_points` | 诊断发现的薄弱知识点列表 | diagnose |
| `student_grade` | 推断或用户指定的年级 | 任意 |
| `answered_correctly` | 答对的知识点（避免重复出同类题） | generate |

### 典型闭环：错题补强

```
diagnose → 发现薄弱点
  → learn（补强，选择一种内容形式）
  → generate（验证，从夯基题开始）
  → diagnose（再次诊断确认掌握）
```

### 进阶闭环：思维训练

```
基础训练 → Polya四阶段训练 → Friedman八步法训练
  → 结构化学习（一题多解）→ 数学思维专项训练 → 综合应用
```

## 📊 知识图谱可视化

本 skill 提供交互式知识图谱可视化功能。

**主要特性**：
- **依赖关系展示**：清晰显示知识点间的 prerequisite 关系
- **交互式探索**：拖拽节点、缩放视图、点击查看详情
- **多维度筛选**：按年级、知识点类型、领域聚类筛选
- **学习路径规划**：基于依赖关系推荐学习顺序

**使用方法**：
1. 打开 `assets/visualization.html` 文件
2. 选择要查看的年级和知识点类型
3. 交互式探索知识图谱
4. 导出当前视图为图片

## ⚠️ 注意事项

1. **出题必须正确**：计算题生成后自己心算验证，不能出错
2. **中文输出**：全程中文，符合人教版表述规范
3. **模板变量处理**：`assessmentPrompt` 里的 `{{name}}` 替换为学生姓名（如已知）或去掉
4. **跨册引用**：依赖链追溯到跨册前置时，说明"这个知识点在 X 年级 X 册中学过"
5. **禁止联网**：所有数据均为本地文件，不执行 `git clone` / `git push` / 任何网络请求
