# 初中数学自适应辅导系统

孩子的错题总也改不对？想刷题却找不到合适的题？希望他不只是会算，更能"想明白"？

这套系统把 **Polya、Friedman、孙维刚、王屏山与傅学顺** 等经过教学实践验证的数学方法，装进了一个随叫随到的"AI 私人数学教练"。你**不需要懂任何教学法，也不用写代码**——像日常聊天一样说话，它就知道该怎么做。

## 使用方法

**简单对话就能获得专业辅导**：

- 提到"错题"/"做错了"/"不会"/"扣分" → 进入 **diagnose**，智能诊断错题原因
- 提到"出题"/"练习"/"考考我" → 进入 **generate**，生成个性化练习题
- 提到"学习"/"自学"/"看懂"/"思维导图"/"视频"/"怎么理解" → 进入 **learn**，多种学习方式
- 提到"教材"/"新学期"/"PDF"/"扩展图谱" → 进入 **build**，构建知识体系
- 提到"polya"/"解题思路"/"解题方法"/"四阶段" → 进入 **polya**，应用问题解决框架
- 提到"friedman"/"解题步骤"/"八步法"/"训练" → 进入 **friedman**，系统化解题训练
- 提到"孙维刚"/"结构化"/"一题多解"/"多题归一" → 进入 **structural**，结构化学习
- 提到"王屏山"/"傅学顺"/"思维能力"/"分析"/"归纳"/"类比" → 进入 **thinking**，数学思维训练

**不确定时直接问**：「你想诊断错题、练习出题，还是学习某个知识点？」

| 你想解决的事        | 一句话效果                                       |

## 🧠 核心数学思维框架

### Polya 四阶段问题解决循环

**默认的问题解决流程**：

1. **理解问题** - 识别未知、数据、条件、可行性、符号表示
2. **制定计划** - 通过相关问题、定理、变换、辅助元素或更易处理的相关问题连接数据与未知
3. **执行计划** - 执行每个步骤并检查每一步是否合理
4. **回顾反思** - 验证答案、简化解法、寻找替代推导、重用方法

**失败模式**：先计算后理解。如果学生无法重述问题或命名未知，返回阶段1。

### Friedman 八步解题训练法

**用于辅导或分析学生作业**：

1. 分析问题
2. 做表征或图表
3. 找解法
4. 执行解法
5. 检查解法
6. 讨论问题：存在性、解的数量、条件
7. 清晰陈述答案
8. 分析完成的解法，寻找更好的方法、推广和迁移

### 孙维刚结构化学习

**强调将每个知识点放入系统中学习**：

- 将新知识点与早期定义和定理连接
- 使用规则前询问为什么规则为真
- 在特殊和一般情况间转换
- 比较同一问题的多种解法
- 将多个问题压缩为一个共同方法

### 王屏山傅学顺数学思维能力模型

**基于《数学思维能力的训练》（王屏山、傅学顺编著）**：

将数学思维分解为六大可训练能力：

- **分析能力**：分解已知、要求和关系，进行条件-需求分解
- **设想能力**：假设问题已解决，检查必须为真的条件，包括"设想问题已解"
- **归纳能力**：列举、猜测、验证，包括穷举归纳、枚举归纳、数学归纳
- **模仿能力**：映射关系，而非表面词汇，转移已解决问题的操作序列
- **类比模拟能力**：在不同领域间迁移方法，包括类比、模拟、等价变换
- **逻辑推理能力**：定义、命题、推论、反例，包括概念、定义、命题、推论方向

## 📊 知识图谱可视化

内置交互式知识图谱，把零散的知识点连成一张"地图"：

- **依赖关系展示**：清晰显示知识点间的 prerequisite 关系
- **交互式探索**：拖拽节点、缩放视图、点击查看详情
- **多维度筛选**：按知识点类型、领域聚类筛选
- **学习路径规划**：基于依赖关系推荐学习顺序

**查看方法**：

1. 打开 `visualization_8up.html`，查看 **人教版八年级数学上册 知识图谱** 的交互式可视化
2. 拖拽、缩放、点击节点，查看知识点详情与依赖关系
3. 按知识点类型或领域聚类进行筛选
4. 导出当前视图为图片

### 🎯 高级思维模式

#### Polya 问题解决模式

**应用场景**：当学生需要系统性的解题指导时

**核心流程**：

1. **理解问题** - 使用启发式问题引导学生识别未知、数据、条件
2. **制定计划** - 通过类比、特殊化、一般化等方法寻找解题路径
3. **执行计划** - 强调每一步的合理性检查
4. **回顾反思** - 验证答案、寻找多种解法、提炼通用方法

**输出模板**：

```
🧠 Polya解题分析

━━ 第一步：理解问题 ━━
• 未知：[需要求解的内容]
• 数据：[已知条件]
• 条件：[约束条件]
• 可行性：[是否有解的判断]

━━ 第二步：制定计划 ━━
• 相关问题：[类似问题或定理]
• 解题策略：[选择的解题方法]
• 辅助元素：[可能需要的辅助线、辅助变量等]

━━ 第三步：执行计划 ━━
• 步骤1：[具体计算或推理过程]
• 步骤2：[继续执行过程]
• 每步验证：[每一步的合理性检查]

━━ 第四步：回顾反思 ━━
• 答案验证：[结果是否正确]
• 解法优化：[是否有更简洁的方法]
• 方法推广：[此方法可用于哪些其他问题]
```

#### Friedman 训练模式

**应用场景**：需要系统化训练学生解题能力时

**核心流程**：

1. **问题分析** - 分解题目条件和要求
2. **表征构建** - 画图、列表或建立数学模型
3. **方法寻找** - 识别问题类型，选择解题策略
4. **执行解法** - 按步骤求解
5. **结果检查** - 验证答案的正确性
6. **深度讨论** - 分析解的存在性、唯一性、条件依赖
7. **清晰表达** - 用数学语言规范表述
8. **方法提炼** - 总结解题规律和迁移价值

#### 结构化学习模式

**应用场景**：学生需要建立知识体系和解题思维时

**核心原则**：

- **一题多解**：从不同角度理解问题结构
- **多题归一**：发现不同问题的共同本质
- **结构连接**：将新知识与已有知识网络连接
- **超前思维**：鼓励学生预测、推导、质疑

#### 数学思维训练模式

**应用场景**：需要针对性培养特定数学思维能力时

**能力分类训练**：

- **分析能力**：分解复杂问题为简单要素
- **设想能力**：假设结论成立，推导必要条件
- **归纳能力**：从特例发现一般规律
- **类比能力**：在不同数学领域间迁移方法
- **变换能力**：等价变形和问题转化
- **逻辑推理**：严格证明和反例构造

### 跨模式状态传递

在同一次对话中，各模式共享：

- `diagnosed_weak_points`：diagnose 发现的薄弱知识点列表
- `student_grade`：推断或用户指定的年级
- `answered_correctly`：generate 中答对的知识点（避免重复出同类题）

典型闭环：

```
diagnose → 发现薄弱点
  → learn（补强，选择一种内容形式）
  → generate（验证，从夯基题开始）
  → diagnose（再次诊断确认掌握）
```

#### 高级思维训练闭环

```
基础训练 → Polya四阶段训练 → Friedman八步法训练 →
结构化学习（一题多解）→ 数学思维专项训练 → 综合应用
```
